# Hospital Management System

Simple mini project using **Python + Tkinter + Excel (OpenPyXL)**.

## Features
- User registration and login
- Dashboard with patient and appointment counts
- Patient Add, View, Search, Update, Delete, Clear
- Gender dropdown: Male, Female, Other
- Blood Group dropdown: A+, A-, B+, B-, AB+, AB-, O+, O-
- Appointment Add, View, Search, Update, Delete, Clear
- Appointment Status dropdown: Scheduled, Completed, Cancelled
- Excel used for permanent data storage
- Simple hospital-style GUI

## Run
```bash
pip install -r requirements.txt
python main.py
```

Registered users and all records are stored in `hospital_management.xlsx`.
